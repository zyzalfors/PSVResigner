# PSV Resigner
This GUI tool, written in PowerShell and leveraging the older WinForms framework, allows users to resign non-console-specific PlayStation 3 PSV files for PlayStation and PlayStation 2 saves.

After downloading, the program can be launched by clicking PSVResigner.bat. No installation or additional dependencies are required, providing a quick (but Windows-only) way to resign PSV files.

Other similar repositories are:
* https://github.com/dots-tb/ps3-psvresigner
* https://github.com/bucanero/psv-save-converter/tree/master/src
